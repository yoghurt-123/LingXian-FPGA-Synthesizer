## 本轮新增：钢琴八度（Z降 / X升）

| 按键 | 功能 | Keyboard页usage |
|---|---|---|
| Z | 八度降一档（低/原/高三档，边界饱和） | 0x1D |
| X | 八度升一档 | 0x1B |

- 档位 0=低八度、1=原八度、2=高八度（-1/0/+1）；上电/复位为原八度；按下沿一档、长按/重复报告不连调；Z+X同持不调、先持一键再按另一键忽略、松开不补发。
- **仅USB手动钢琴音**有效；触摸/板载KEY0/歌曲/演示保持原音高；吉他模式不动作（选择保留，切回钢琴继续用）。
- 同报告"Z/X+音符"：该音符用调整后的新音区起音；已响音符音高不变（音区在起音时锁存）；松开同键重按才用新档位。
- 模式切换/Esc同拍丢弃调档（保持位继续跟踪），Space期间允许调档但不发新音；断连保留档位，重连须先松开两键。
- 实现：`usb_key_snapshot`新增Z/X两位随快照握手（payload 33位，旧位序不变）；新增`usb_octave_control.v`（边沿/冲突/饱和/resync，输出锁存档位+同拍组合档位）；`usb_piano_keys`新增`trig_oct`与音符同拍；声部新增`octave`输入、起音锁存`octave_lat`（`pending_octave`随最后一次请求覆盖）；**相位累加保持原步进，另加1位扩展位构成33位相位，正弦地址按锁存档位取位段**（低=÷2、原=×1、高=×2）——原八度逐位等价、不新增乘法器，每声部仅约+20 LUT。
- 限制：需上板确认Z/X实际报告为标准Keyboard页0x1D/0x1B（若键盘布局不同或为组合码，先记录真实报告再调整，不盲猜）。

## 本轮新增：吉他左右弯音（← / →）

| 按键 | 功能 | Keyboard页usage |
|---|---|---|
| 左箭头 | 弯音 -200 音分（-2半音） | 0x50 |
| 右箭头 | 弯音 +200 音分（+2半音） | 0x4F |

- 两键同按或全松=0；按住保持目标，松开约30ms（1448采样）平滑回中；方向键自身不产生新音。
- 只作用于**最近一次实际被声部接受的USB手动吉他主奏**：槽号+代次绑定；槽被任何来源重新触发后旧事务不再作用；切换主奏时旧音平滑回中、新音从基准音高平滑进入。
- 途中反向从当前实际偏移重新规划；终点精确、单调无过冲。
- 模式切钢琴/演示/断连使目标失效（平滑回中）；断连后需先松开箭头再按（resync）；Esc同拍失效、kill后清事务恢复1.0；Space（吉他制音）期间目标0。
- 同拍多音按 guitar_ctrl 原有固定调度顺序逐采样执行，最后一个被接受的USB拨弦成为主奏。
- 实现：快照新增左右箭头两位（payload 35位，旧位序不变）；新增 `pitch_bend_ctrl.v`（目标/斜坡/6槽倍率换算/代次）与 `bend_ratio_rom.v`（1/16半音栅格、±14.5半音、1BSRAM）；`guitar_ctrl` 新增USB来源位随pending/替换传递；`guitar_voice` 步长预取加一级32×24乘法+取整+Nyquist饱和（1 DSP块），原八度/零弯路径逐位等价（等价性测试）。
- 尺寸：全设计 DSP +3（70.5→73.5）、BSRAM +2（37→39）、LUT +712；最差音频 slack +0.005ns，余量很小。
- 限制：需上板确认方向键为标准Keyboard页0x4F/0x50；30ms 时长可按听感调整（只改 `RAMP_SAMPLES` 一处）。

## 历史状态（Esc与钢琴Space，已上板验收）

### 钢琴Space（仅钢琴模式）
- 按下沿：取消钢琴歌曲后续调度与全部钢琴pending；16个modal声部与板载KEY0参考音进入1024采样（≈21.22ms）平滑释放；释放到零清playing/pending/busy/data。
- 保持期间：触摸、板载、USB全部拒绝新起音/歌曲启动；重复按空格不重置、不抬升增益、不动音龄/相位。
- 松开后：旧按住键不补发；重新按下恢复正常演奏。
- 不触发全局混响清零，不改变模式/效果选择。

### 吉他Space（保留已验收行为，本轮补齐一致性）
- 按住空格时，触摸/板载/USB的所有吉他拨弦与演示启动统一拒绝（原先仅USB侧被门控）。
- 断连清理、按下沿制音、松开不补发等原规则不变。

### Esc（任意模式，紧急全静音）
- 有效按下沿当拍（组合cancel_now）取消一切：歌曲/两首演示停止、guitar_ctrl请求锁存/扫弦/替换清空、全部输入来源新演奏阻断；**停止事件不等淡出完成**。
- 最终PCM自当前增益用241采样（≈4.994ms）整数精确淡出到0（商余数法，135/136交替，恰好在第241采样归零）。
- 到零后kill_commit：钢琴/吉他声部强制终止、guitar_fx历史清零、混响10240字顺序清零（2048拍≈39us，写入与正常反馈互斥，BSRAM推断保留）；清理完成前保持静音。
- 恢复条件：清理完成且Esc已松开（电平判断；断连把Esc视为松开，不卡死）。旧按键需松开重按，不排队重放。
- 优先级：reset > Esc/panic > 模式切换 > Space > 正常音符。Esc与F1/F2/F3/F5同报告时不执行它们；Esc无需等“全部键松开”。
- 原模式、清音/过载与混响选择保留；不复位USB/UART/PLL。
- DAC与VOFA共用同一份处理后PCM；淡出/清理期间保持发送，音频为0后至少确认2整帧（覆盖在途旧帧）再允许停流（vofa_uart新增frame_done）。
