结论：**没有找到可合法使用的准确乐谱/MusicXML/MIDI，因此没有编造音符，也没有生成《Let It Be》的 performance.bin。** 已完成能力核验、格式工具和原创技术样片；正式曲目编配等待有授权的乐谱输入。

## 1. 参考版本

用户指定的官方试听页：

`https://www.thebeatles.com/let-it-be-3`

页面确认这是 The Beatles 的 **Let It Be** 官方音乐视频，视频由官方发布；页面不是乐谱，也不提供 MIDI、MusicXML 或可下载音符数据。没有把试听链接当作乐谱来源。

用于交叉核对歌曲元数据（不是编配输入）：

- Wikipedia `Let It Be (song)`：
  - 单曲版长度约 3:50，专辑版约 4:03。
  - 词曲署名 Lennon–McCartney；单曲/专辑制作人分别为 George Martin / Phil Spector。
  - 记录为 1969 年录制、1970 年发行。
- SongBPM `The Beatles — Let It Be`：
  - 页面给出的算法检测为 C 调、4/4、144 BPM，并注明可按半速 72 BPM 理解。
  - 144/72 是算法/页面信息，**不是权威乐谱速度**；M0 不据此锁定 BPM，也不把 144 或 72 当成默认工程 BPM。
- Musicnotes 搜索页：
  - 存在官方授权渠道的 Piano/Vocal/Guitar、Piano Solo、Leadsheet 等商品。
  - M0 没有购买、下载或复制任何该页面乐谱；也没有把商品页的预览图转成音符数据。

**版本决定必须先解决**：单曲版 3:50、专辑版 4:03 或官方视频版本可能有不同剪辑/间奏。不能把不同录音版本的段落、独奏或尾段拼接。

## 4. 三乐器改编原则（待乐谱输入后执行）

- **钢琴**：承担原唱旋律的主陈述；在不与旋律同键冲突时加入 1–2 个和声音；避免同键跨八度重叠和小于约 21 ms 的同键重触发。
- **吉他**：承担节奏扫弦/分解和弦、回应乐句或间奏；必须按“E2 独立 + 3 个动态池槽”的上限编排，不能假设六弦独立复音；共享 overdrive/reverb 只在段落边界切换。
- **鼓**：保留重拍、轻拍、踩镲变化和加花；同采样点同组鼓统一力度，或明确写出微小时差；开/闭镲 choke 要单独验证。
- **贝斯**：先按授权乐谱列出音高；低于吉他 E2 或钢琴 C3 的音需要移调/换八度/换声部，并在改编报告中逐项记录，不静默删音。
- **效果**：A2/A3 不参与；不存在真实 Echo/Delay。重复弱音只能标为“重复触发”，不能标为“回声”。

## 5. 需要用户/编曲方提供

请提供以下任一项，并确认使用范围：

1. 有授权的 MusicXML（首选，保留声部/力度/速度/小节）。
2. 有授权的 MIDI，并注明来源、版本和允许转换/分发范围。
3. 已核对的小节级乐谱 PDF/扫描件，且允许我们转换为项目内部数据。

收到后按同一 `score.json` schema 录入，先做连续 8 小节，再扩展 60–90 秒；每次转调、换八度、删音、合并声部都进入适配报告。
