# USB键盘连接底层（本轮：钢琴16键 + 吉他六弦/空格 + 功能键F1~F6）

全部连接文件采用英文文件名。`usb_keyboard.v` 为本项目中文注释封装，供主工程 `top.v` 调用；钢琴16键、吉他六空弦+空格制音均已上板验收；本轮新增 F1~F6 功能键映射（仅复用已有功能）。

| 文件 | 用途 |
|---|---|
| usb_keyboard.v | PLL、主机、键位保持状态封装（输出16位钢琴保持 + 空格保持 + F1~F6保持 + 键盘在线） |
| usb_key_snapshot.v | 完整8字节报告解码16钢琴usage + 空格(0x2C) + F1~F6(0x3A~0x3F) + Esc(0x29)；稳定数据 + 请求/确认跨时钟握手；连接状态只随真实有效报告建立 |
| usb_piano_keys.v | 钢琴保持状态→音频域单拍触发（按下沿一次；模式/断连/同拍模式切换/blocked期间拒绝新触发且不补发） |
| usb_guitar_keys.v | 吉他六弦按下沿单拍拨弦（每键一位）+ 空格制音/断连清理脉冲；仅吉他模式有效 |
| usb_func_keys.v | F1~F6功能请求：指定模式/效果/混响/演示启停；仅单拍请求，复用原guitar_ctrl与演示控制；Esc同拍/期间取消 |
| usb_velocity_control.v | 手动力度选择：小键盘1/2/3(0x59/5A/5B)按住选档+左Shift(+2饱和15)；组合自同一份快照，同拍生效 |
| usb_volume_control.v | 总音量：F8(0x41)减/F9(0x42)加；17档每档6.25%、按下沿一档、1024采样整数斜坡；Esc/模式切换同拍丢弃，断连保持档位 |
| usb_hid_host.v | 已验证的低速USB HID主机及UKP协议控制 |
| usb_hid_host_rom.v / .hex | 枚举微程序；读取路径为 src/usb/usb_hid_host_rom.hex |
| usb_pll.v / usb_pll_mod.v / pll_init.v | 50MHz转12MHz与60K PLL初始化 |
| USB_HOST_LICENSE | 上游许可证 |
| usb_a_key.v | 早期A键单键模块（未接入，保留供参考） |

音频52.5MHz保持原OSCA；USB的50MHz输入独立来自V22。

吉他映射（仅吉他模式；复用同一份物理保持位，在 usb_guitar_keys 内按吉他音高表再映射）：

| 按键 | 音名 | usage | 说明 |
|---|---|---|---|
| A | E2 | 04 | 直达槽0（专用弦） |
| S | A2 | 16 | 经原单音弦池分配（槽3..5） |
| D | D3 | 07 | 同上 |
| F | G3 | 09 | 同上 |
| G | B3 | 0A | 同上（注意不是钢琴的G4） |
| H | E4 | 0B | 同上（注意不是钢琴的A4） |
| 空格 | 全局平滑制音 | 2C | 优先取消待执行拨弦/扫弦/替换请求；按住期间不拨弦；停止演示后续事件；断连时仅吉他模式自动清理 |

限制：A2/D3/G3/B3/E4 共用3个池槽，最多同时3个；第4个按原"最早触发"替换规则处理（先1~2ms淡出再写音色触发）。

功能键映射（HID 0x3A~0x3F；标准usage，已上板验收）：

| 按键 | usage | 功能 | 边界 |
|---|---|---|---|
| F1 | 3A | 指定钢琴模式 | 已在钢琴时不动作；同拍F1+F2冲突忽略 |
| F2 | 3B | 指定吉他模式 | 已在吉他时不动作；同拍F1+F2冲突忽略 |
| F3 | 3C | 清音/过载切换 | 仅吉他模式；复用原fx_key；不拨弦 |
| F4 | 3D | 混响开关 | 仅吉他模式；复用原混响选择；不拨弦 |
| F5 | 3E | 演示1开始/停止 | 仅吉他模式；另一首在播不启动；与空格同拍不启动 |
| F6 | 3F | 演示2开始/停止 | 同上；同拍F5+F6冲突都忽略 |
| Esc | 29 | 全局紧急制音 | 任意模式；241采样淡出+清理+终止零帧；已上板验收 |

力度修饰（按住临时选择，松开恢复默认；仅影响之后的新起音；已上板待测）：

| 操作 | usage | 新起音力度 | 同按左Shift |
|---|---|---|---|
| 不按力度键 | — | 75% | 87.5% |
| 小键盘1 | 59 | 56.25% | 68.75% |
| 小键盘2 | 5A | 75% | 87.5% |
| 小键盘3 | 5B | 100% | 100% |

功能键均仅按下沿触发一次；板载/触摸与USB同功能请求同拍合并为一次；模式切换优先于同拍USB音符/效果/演示；Esc优先于模式切换/效果/演示；力度修饰在Esc/Space/模式切换期间继续跟踪但不发声。

来源：同目录上级项目TangMega60K_usb已验证版本；上游为Sipeed示例引用的AlanCui4080/sipeed_usb_hid_host_138k，60K PLL来自TangMega-60K-example。
